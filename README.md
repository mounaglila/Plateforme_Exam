# Online Exam Management System

## Description
This project is a web-based application for managing online examinations. It provides a platform for administrators to create and manage exams, and for students to participate in them remotely.

The system ensures a structured and efficient examination process, including exam creation, submission, and evaluation.

## Features

### Administrator
- Create and manage exams
- Add and manage questions
- Define exam duration and rules
- Monitor student participation
- Evaluate submissions and assign grades

### Student
- Access available exams
- Pass exams within a defined time limit
- Submit answers online
- View results

## Technologies Used

### Frontend
- React.js
- HTML5
- CSS3
- JavaScript

### Backend
- Node.js
- Express.js

### Database
- MongoDB Atlas

### DevOps / Deployment
- Docker
- Docker Compose

## Architecture
The application follows a client-server architecture:
- Frontend: React application
- Backend: REST API built with Node.js and Express
- Database: Cloud-hosted MongoDB Atlas
